# 资产快捷生成

在「资料 → 资产」新建角色、设定或进阶体系时：

- 点击「生成 ID」填入合法标识，避开当前列表已有 ID；保存时仍由服务端检查冲突。
- 在「按条件生成（本地模板）」选择题材，角色可指定姓氏，设定可选择命名类别。点击「随机名称 / 换一批」，再点击候选名称填入。
- 进阶体系可指定能力方向和 1–12 个阶段，点击「生成阶段与能力 / 换一批」，预览后采用。已有阶段需要勾选允许替换。
- 每个阶段可编辑名称、能力、限制和晋升条件，列表字段每行一项；阶段 ID 必须合法且唯一。
- 点击「创建」才写入新资产；编辑已有体系时点击「保存」写入阶段修改。

体系类型在中文界面显示为能力、等阶、修炼、职业、声望、诅咒、自定义，存储值保持兼容。

「按条件生成（本地模板）」使用本地词库，不调用模型。

## AI 生成

新建角色、设定、进阶体系及编辑已有资产时，点击「AI 生成」：

1. 选择「任务 → 模型」中已配置的对话模型；不指定时使用大纲规划（goethe）路由或默认模型。不会修改现有模型路由。
2. 输入题材、风格、姓氏、能力方向等生成要求。进阶体系可指定 1–12 个阶段。
3. 可勾选附带当前作品的设定和进阶体系。此选项将发送有长度上限的资产内容给所选模型，不发送全文稿件。
4. 生成名称候选或完整草稿。生成会消耗模型额度，结果不会自动保存。
5. 完整草稿逐字段预览。已有内容默认不勾选；勾选表示替换该字段。采用后可以继续编辑，最后点击「创建」或「保存」。ID 仍由程序生成。

错误时显示提示并允许重试；不会自动重试付费请求。每个作品同时只执行一个资产生成请求。模型响应最长等待约两分钟。

当前随插件的受管理后端提供此接口。若手动连接外部 Core，外部服务也需要提供兼容的 `/api/assets/generate` 接口。
